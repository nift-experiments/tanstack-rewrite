# Retained shell feasibility

This CSR-only representative proof retains 95 byte-preserved upstream UI runtime source files and one compile-time redirect helper. Provenance lists the pinned upstream SHA and file hashes. The original package side-effect policy is retained. The build reuses the frozen dependency installation read-only; independently installed release dependencies remain pending.

The browser-only build contains no original source worktree, route modules, server-source modules, or publication renderer imports. Nift composes maintained-source article projections with explicit file dependencies. Router navigation fetches the resulting publication HTML; shell updates preserve native article ownership.

The local service proof owns auth definitions/protocol. One observed GET endpoint remains a controlled upstream service oracle. This does not certify the complete replacement backend. Public Algolia read queries and badge responses are header-free snapshots under fixtures; ordinary proof runs replay them and reject missing fixtures. Explicit CAPTURE_PUBLIC_FIXTURES=1 permits capturing additional public read responses. Their capture dates are distinct from the pinned source revision.

Full SSR/hydration, layout/sidebar/footer, route coverage, production CSS/fonts, real provider/database/chat integration and R3 acceptance remain pending. These are feasibility receipts, not benchmark numbers.
